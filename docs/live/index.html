How it stays live

Your GitHub repository is the source. GitHub Actions publishes the site and allowed bank files to GitHub Pages. The app compares published revisions and reloads the new site automatically.

Change docs/live/index.html to update this interface. Add or edit files in live-bank/ to update the file bank. Only changes on main get published.

Changes to Android Kotlin code still require rebuilding the APK.
